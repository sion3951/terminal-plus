How to use

Enter examples/html/index.html at a new Bash prompt, or open it from Files. Follow the links and try the controls.

Ctrl+F finds text. Ctrl+mouse wheel zooms. The Source button shows the file. Esc closes the document.

Compatibility status

These pages exercise implemented native features. They do not establish complete browser compatibility. CSS transforms/animations, full web APIs, WebGL and some advanced layout/JavaScript behavior remain outside the implementation.
